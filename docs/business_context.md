# Business Context

## Humanitarian Scenario

This project simulates a realistic humanitarian operation in Eastern Democratic Republic of Congo.

A fictional NGO called "Relief Action Kivu (RAK)" conducts Non-Food Item (NFI) distributions for internally displaced households.

The intervention area includes:

* Goma
* Nyiragongo
* Rutshuru
* Masisi

---

## Operational Context

The region is affected by:

* Population displacement
* Security constraints
* Limited infrastructure
* Connectivity challenges

Field teams collect beneficiary information using KoboToolbox on mobile devices.

Data is sometimes collected offline and synchronized later when internet access becomes available.

---

## Current Reporting Process

The existing process is highly manual:

1. Export data from KoboToolbox
2. Download CSV files
3. Clean data in Excel
4. Consolidate files manually
5. Produce Power BI reports

This process can take several days or even weeks.

---

## Challenges

### Data Quality

Common issues include:

* Duplicate beneficiaries
* Missing information
* Incorrect dates
* GPS inconsistencies

### Reporting Delays

Management teams often receive information too late.

This impacts:

* Operational decisions
* Resource allocation
* Donor reporting

### Monitoring Challenges

Without automated controls:

* Errors remain undetected
* Indicators become unreliable
* Trust in data decreases

---

## Project Goal

The goal is to create a complete data pipeline that automates the reporting process.

The solution includes:

* Data extraction
* Data cleaning
* Data quality checks
* Database storage
* Dashboard generation

---

## Expected Benefits

### For MEL Teams

* Faster reporting
* Better data quality
* Standardized indicators

### For Operations Teams

* Better visibility of distributions
* Faster identification of issues

### For Management

* Real-time decision support

### For Donors

* More reliable reporting

## Why This Project Matters

Humanitarian organizations increasingly rely on data to make decisions.

This project demonstrates how data analytics, automation and reporting can improve humanitarian operations while reducing manual workload.
